## Rules that came out of this script
- About 200–240 words for 60–75 s. Full sentences, joined with "and / so / where / with".
- 4–6 named spots. Each: name + one concrete detail (dish, price, size, year, what's inside). No adjectives without a fact behind them.
- Second person ("you can", "come around sunset") puts the viewer there.
- One plain reaction at most per section ("basically an art gallery"). No jokes, no "here's the thing", no hype words.
- Present tense only for things verified as current. Past tense for seasonal events seen in old footage.
- Every noun you say must have a shot. If there's no clean footage for a spot, cut the spot from the script (we cut BLOOMARKET and the McDonald's concept store for this reason).
